# 시연 화면 — 2026-09-10

## 회의에서 짚을 만한 것

**3번이 핵심입니다.** 지난 회의의 "자연어 요청과 1회 확인 중심으로 단순화"가
그대로 담겨 있습니다. 외울 명령이 없고 입력이 두 번입니다.

**6번의 대비**도 눈여겨볼 만합니다. 처리 결과는 누른 사람에게만 보이고,
완료 공지만 방 전체에 나갑니다 — 대화방이 남의 처리 내역으로 지저분해지지
않습니다. 공지는 **앱 이름(기술지원 도우미 BOT)**으로 나가 자동화가 한 일임이
드러납니다.

**1번에서 계약정보·설치정보가 없는 것**은 버그가 아닙니다. 실 CRM API 응답에
항목 자체가 없습니다. 필요하면 필드 추가를 요청해야 합니다.

## 화면에 없는 것

- **두레이 웹에서 직접 완료한 경우** — 원 요청에 인용 답장이 달립니다.
  버튼 경로와 달리 최대 5분 걸립니다(상태 변경에 알림이 없어 폴링으로 잡음).
- **되돌리기를 실제로 누른 화면** — 5번의 버튼을 누르면 그 건이 목록에 다시
  나타납니다.
- **양식 경로** (`#이전` → `#기술정보`) — 자연어로 대체되어 시연에서 뺐습니다.
  전화로 받아 적을 때는 여전히 유용합니다.
