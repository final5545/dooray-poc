# Dooray Extension Agent PoC — 문서 세트

연합인포맥스 AI부 / AX추진단 관련 PoC 자료.
Claude Code 등에서 컨텍스트로 사용하기 위해 정리한 문서입니다.

## 🟢 현재 상태 (2026-09-02)

**양방향 봇 프로토타입 동작 확인.** AI 프리미엄 라이선스 없이,
개인 액세스 토큰 기반 **자체 구현**으로 전환했습니다.

```
개인 액세스 토큰 → 소켓 토큰 → WebSocket 수신
  → 화이트리스트 → 루프 차단 → 명령 처리 → REST 송신
```

검증 코드: `standalone/probe.py` (원본 덤프) / `standalone/agent.py` (실사용 형태)

### 용도별 읽기 순서

- **코드 작성** → **`06`(1순위)** + `02`(SDK 함정)
- **현황 파악·보고** → `03`
- **우회 방식의 근거** → `02` §0, §2
- **배경·판단 근거** → `00`
- **개념·아키텍처** → `01`
- **방식 선택·전환 판단** → `07`
- **정식 방식(익스텐션 에이전트) 검토** → `04` + `05`

> ⚠️ `01`은 SDK 리팩터링 **이전** 문서라 샘플 코드가 동작하지 않습니다
> (`@agent.messenger`, `event.user_id`, `req.reply()`).
> Claude Code 컨텍스트에 넣으면 구형 API를 따라 쓸 위험이 있으니 제외하십시오.
>
> ⚠️ `04`/`05`는 **익스텐션 에이전트 기준** 문서입니다. 현행 자체 구현과
> 다른 부분이 있으며, 특히 `05`의 "파일 첨부 수신 불가" 추정은 실측에서 뒤집혔습니다.

## 우선순위 요약

| | 상태 |
|---|---|
| 🟢 수신·송신 | **실측 성공** — 왕복 0.45초 |
| 🟢 페이로드 구조 | **파악 완료** (`03` §6 / `06` §4) |
| 🔴 대화방 전체 메시지 유입 | **확정.** 초대 게이트가 없어 정식 방식보다 범위가 넓음 |
| 🔴 마크다운 표 | **미지원 확정.** 인라인 코드만 렌더링 |
| 🔴 Task/Wiki API | 패키지에는 있으나 공식 문서에 없음 — 현황판 기획이 여기 의존 |
| ⚠️ 토큰 권한 | 개인 토큰 = 본인과 동일 권한. 봇 전용 격리 불가 |
| ⚠️ 동시 접속 | 토큰당 1개 (`1008`) — 환경별 토큰 분리 필요 |
| ⬜ CRM 조회 로직 | 다음 착수 대상 |

## 환경 정보

- Dooray 도메인: `infomax.dooray.com`
- 사무망 아웃바운드: ✅ 실제 WSS 세션 수립으로 확인
- 서버망(ai-node) 아웃바운드: ⬜ 미확인
- 배포 예정: Docker Swarm (ai-node-1/2/4)
- **토큰은 환경별로 분리** — 같은 토큰 동시 사용 시 한쪽이 조용히 STANDBY로 빠짐
- 런타임 의존성: `requests`, `websocket-client`, `certifi` (SDK 불필요)
