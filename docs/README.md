# Dooray Extension Agent PoC — 문서 세트

연합인포맥스 AI부. AI 프리미엄 라이선스 없이 개인 액세스 토큰과 사내 서버만으로
Dooray 봇을 만든 기록입니다.

## 현재 상태 (2026-09-03)

**전 구간 동작합니다.** 고객정보 조회부터 요청 접수, 업무 등록, 버튼 처리,
완료 통보까지 실제 대화방에서 한 바퀴 확인했습니다.

```
정원석 맥                        ai-node-1 (Docker Swarm)
├── agent.py                     ├── dooray_command
│   소켓 수신 (아웃바운드)       │   /처리 · /접수 · 버튼 (인바운드)
│   고객 조회 · 요청 접수        │   https://dooray.infomaxai.com
│   완료 감지 폴링 300초         │
└── mock_crm.py :8900            └── mockcrm :8900
```

## 확인된 것 · 못 넘은 것

| | |
|---|---|
| 🟢 메시지 수신·발신·인용 답장 | 소켓 + 메신저 API |
| 🟢 업무 등록·상태 변경·본문 수정 | Project API |
| 🟢 **슬래시 커맨드와 버튼** | 연동 서비스 앱 (`/처리` `/접수`) |
| 🟢 **봇 이름으로 발신** | `responseUrl` — 호출 맥락 안에서 |
| 🟢 내 Dooray! News 알림 | 채널 ID == 내 memberId |
| 🟢 남에게 개인 알림 | 1:1 대화방 |
| 🟢 인바운드 경로 | ai-node + Traefik + Let's Encrypt |
| 🔴 **남의 Dooray! News에 쓰기** | 그 채널의 멤버가 아님. 시스템 봇 권한 필요 |
| 🔴 일반 메시지의 버튼 클릭 | 어느 앱 것인지 Dooray가 모름 → 커맨드 응답으로 우회 |
| 🔴 여러 줄 슬래시 커맨드 | 개행이 들어가면 일반 메시지가 됨 → 방 로그 조회로 우회 |
| 🔴 상태 변경 자동 알림 | Dooray가 보내지 않음 → 폴링 또는 버튼으로 대체 |
| 🔴 마크다운 표 | 미지원. 인라인 코드만 렌더링 |
| ⚠️ 토큰 권한 | 개인 토큰 = 본인과 동일 권한. 봇 전용 격리 불가 |
| ⚠️ 동시 접속 | 토큰당 1개 (`1008`) — 환경별 토큰 분리 필요 |
| ⚠️ 대화방 전체 유입 | 초대 게이트가 없어 화이트리스트가 필수 |

**라이선스 없이 못 넘은 것은 사실상 첫 줄 하나뿐이고, 그마저 1:1 대화방으로
대체됩니다.**

## 환경

- Dooray 도메인 `infomax.dooray.com` · 공개 주소 `dooray.infomaxai.com`
- 런타임 의존성 `requests` `websocket-client` `certifi` `python-dotenv` (SDK 불필요)
- 배포 `ai-node-1` 고정 (로컬 빌드 이미지 — 레지스트리에 올리면 제약 해제 가능)
- **토큰은 환경별로 분리할 것** — 같은 토큰을 동시에 쓰면 한쪽이 조용히 대기 상태로 빠진다
- ⚠️ **CRM은 모의 서버이고 데이터는 전부 가짜다.** 시연 때 반드시 밝힐 것
