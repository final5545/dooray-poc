# 익스텐션 에이전트 이용 가이드

> 출처: Dooray helpdesk 공유 페이지 (가이드 작성일 2026.03.19)
> **정식 출시 전 기능. 일부 스펙 변경 가능.**

---

## 1. 🔴 이용 조건 — 라이선스 제약

> 이 섹션이 PoC 착수의 실질적 관문.

- 현재 **특정 테넌트에 한하여** 에이전트 기능 제공 중 (체험 기간)
- **AI 프리미엄 라이선스를 부여받은 이용자에 한해** 마이 에이전트 / 프로젝트 에이전트 / 익스텐션 에이전트 사용 가능
- 체험 기간 동안 **AI 프리미엄 라이선스에 할당된 멤버만** 이용 가능
- **구성원 1인당 익스텐션 에이전트 5개** 생성 가능

### 당사 확인 필요 사항
- [ ] `infomax.dooray.com` 이 체험 대상 테넌트에 포함되어 있는가
- [ ] 담당자(정원석) 계정에 **AI 프리미엄 라이선스**가 할당되어 있는가
- [ ] 할당되어 있지 않다면 부여 절차와 비용

> **1인 5개 생성 가능** → 개발용/운영용 토큰 분리 문제는 자체 해결됨.
> 별도 발급 요청 없이 스튜디오에서 2개 만들면 됨.

## 2. 익스텐션 에이전트란

Dooray! SDK를 활용하여 외부 서비스와 연동을 통해 메시지를 주고받고,
특정 동작을 자동으로 수행하는 에이전트.

사내 시스템을 비롯한 다양한 서비스와의 연동을 통해 Dooray! 내에서 외부 서비스의 작업을 수행.

**핵심 가치**: "외부 서비스와 통합"

---

## 3. 🟢 활성화 및 토큰 발급 절차

> 기존 블로커였던 항목. **자체 발급 가능**으로 확인됨.

기본 상태는 **'사용 안 함'**. 아래 단계로 활성화.

1. Dooray! 접속
2. **서브서비스 > AI 스튜디오 > 익스텐션 에이전트** 설정 화면 이동
3. **새로 만들기** → 익스텐션 에이전트 이름 입력 후 **생성**
4. 상태를 '사용 안 함' → **'사용'** 으로 변경 후 저장
5. **토큰 탭에서 토큰 생성**

### ⚠️ 토큰 취급 주의
**토큰은 최초 한 번만 공개됨.** 분실 시 삭제 후 재생성해야 함.
→ 생성 즉시 안전한 곳에 보관할 것. `.env`에 바로 기입하고 git에 커밋되지 않도록 주의.

### 기본 정보 탭

| 항목 | 설명 | 비고 |
|---|---|---|
| 상태 | 사용 / 사용 안 함 | 기본값: **사용 안 함** |
| 이름 | 직접 입력 | |
| 설명 | 메신저 프로필에 표시되는 문구 | 조직도 사용하는 경우 표시됨 |

## 4. 메신저에서의 사용 방식

- 생성 후 **1:1 대화방 또는 주제 대화방에 초대**하여 사용
- **누구나 자유롭게 대화방에 초대 가능**
- 에이전트가 초대된 대화방에 **메시지 전송 시 해당 에이전트가 메시지를 조회하고 답변을 보낼 수 있음**

### 🔴 개인정보 검토 트리거

> "초대된 대화방에 메시지 전송 시 에이전트가 메시지를 조회"

멘션 여부에 관계없이 **대화방의 모든 메시지가 Extension Agent로 유입될 가능성**이 높음.
즉 사내 대화 내용이 우리 중개 서버로 흘러들어옴.

**대응 필요**
- 핸들러 초입에서 처리 대상이 아닌 메시지는 **즉시 폐기** (로깅도 하지 않음)
- 명령어 프리픽스(`#E23009` 등) 매칭 실패 시 조기 반환
- 로깅 정책 수립 — 원문 저장 여부, 보존 기간
- **누구나 초대 가능**하므로 의도치 않은 대화방에 봇이 들어갈 수 있음 → 허용 채널 화이트리스트 검토

→ 실측으로 반드시 확인 (`03-프로젝트-진척현황.md` §5 페이로드 덤프)

### 상태 표시

| 구분 | 표시 | 동작 |
|---|---|---|
| '사용' | 에이전트명 | 정상 동작 |
| '사용 안 함' | **에이전트명(비활성화)** | 메시지를 보내도 반응하지 않음 |

> 운영 중 긴급 차단이 필요하면 스튜디오에서 '사용 안 함'으로 전환하면 됨.
> 코드 배포 없이 즉시 정지 가능한 킬 스위치.

## 6. FAQ

**Q. 몇 개까지 만들 수 있나요?**
A. 1인당 최대 5개.

**Q. 삭제하면 어떻게 되나요?**
A. 삭제된 에이전트가 참여 중인 대화방에서 더 이상 동작하지 않음.

**Q. 다른 사람의 익스텐션 에이전트를 사용할 수 있나요?**
A. 누구나 대화방에 초대하여 사용 가능.
