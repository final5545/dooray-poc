잘못 눌렀다면

방금 처리한 건에 되돌리기가 붙습니다. 완료하면 목록에서 사라지니, 붙잡을 손잡이는 여기뿐입니다.

  • 어디로 되돌아갈지는 버튼 이름에 적혀 있습니다. 접수에서 완료했으면 되돌리기 (접수), 진행 중에서 했으면 되돌리기 (진행 중) — 같은 완료 버튼이라도 누른 자리에 따라 목적지가 다릅니다.
  • 되돌리면 그 건이 목록에 다시 나타납니다. 거기서 또 누르면 됩니다.
두레이 업무가 실제로 바뀝니다. 화면 문구만 고치는 게 아닙니다 — /처리를 다시 쳐 보면 그 건이 진행 중으로 남아 있고 수락 버튼이 사라져 있습니다.

남의 Dooray! News에는 넣을 수 없습니다. 그 채널의 멤버가 아니기 때문이고, Dooray-Bot이 모두의 News에 쓰는 것은 시스템 봇 권한입니다. 그래서 요청자가 다른 사람이면 1:1 대화방으로 갑니다 — 1:1로 대화한 적이 없으면 개인 알림은 생략되고 대화방 쪽만 남습니다.

켜고 끄기

맥 — 에이전트

$ cd ~/infomax/dooray-poc
$ python standalone/mock_crm.py 8900 &   # 모의 CRM, 먼저
$ python standalone/agent.py             # 이 창은 열어둘 것

기동하면 라우팅 대상 대화방과 폴링 주기가 배너에 찍힙니다. 창을 닫으면 멎습니다.

서버 — 커맨드

$ ssh ai-node1
$ docker service ps dooray_command | head -3     # Running 인지
$ docker service logs dooray_command -f          # 요청이 들어오는지
$ curl -sS https://dooray.infomaxai.com/health   # {"ok": true}

서버는 재부팅해도 Swarm이 알아서 다시 띄웁니다. 평소엔 손댈 일이 없습니다.

안 될 때

증상먼저 볼 곳대개 원인
고객번호를 써도 조용함 맥의 agent.py 창 에이전트가 멎었거나 대화방이 라우팅에 없음
조회는 되는데 "일시적으로 조회할 수 없습니다" lsof -i :8900 모의 CRM이 안 떠 있음
/처리를 쳐도 아무 반응 없음 docker service logs -f 로그에 요청이 안 찍히면 두레이가 우리한테 못 온 것
로그에 appToken 불일치 — 거부 서버 .env 앱 토큰을 다시 발급했는데 서버에 반영 안 됨
버튼을 눌러도 "상태를 변경하지 못했습니다" 두레이 업무 화면 해당 프로젝트에 그 상태가 없거나 권한 부족
버튼으로 완료했는데 방에 공지가 없음 docker service logs 완료 공지 → 전송됨 이 안 찍혔는지 확인
요청자에게 개인 알림이 안 감 docker service logs 개인 통보 생략 — 그 사람과 1:1 대화방이 없음
같은 완료가 두 번 알려짐 맥의 agent.py 에이전트가 옛 코드 — git pull 후 재기동
웹에서 완료했는데 답장이 안 옴 최대 5분 대기 웹에서 바꾼 건은 확인 주기를 기다려야 함
